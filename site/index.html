Why you can trust it

Honest by design

Ratings that admit gaps

Every alternative says how well it replaces the original, which formats work and what is missing. Unchecked entries are labelled “unverified”.

Real Wine & Proton reports

Reports name the app version, runner, distribution and the exact tweaks used. No report means “untested”, not “works”.

Open and reusable

Every entry is a small YAML file in Git. The whole dataset is CC0 and served as a JSON API that other tools can build on.
