Your first pull request

Five steps, no code

  1. Fork the repositoryClick “Fork” on GitHub, or use the web editor to edit files directly.
  2. Copy the templateCopy data/apps/_template.yaml to data/apps/your-app.yaml. The file name must match the id inside.
  3. Fill it inUse neutral, concrete facts. Link a source. New entries stay verified: false; an independent reviewer must check the complete entry before it is marked verified.
  4. Check it (optional)Run npm install, then npm run validate. If you skip this, the same check runs automatically on your pull request.
  5. Open a pull requestOne app per pull request keeps reviews quick. A maintainer will take a look.

What an entry looks like (illustrative example)

id: example-cad
name: Example CAD
vendor: Example Corp
category: cad
homepage: https://example.com/cad
verified: false

alternatives:
  - id: freecad
    fit: partial            # full | good | partial | minimal
    file_formats:
      import: [dxf, step]
      export: [dxf, step]
    missing:
      - Sheet-set manager
    notes: Fine for 3D parametric work, weaker for 2D drafting.
    sources:
      - https://example.com/review

Ground rules

What makes a good contribution

  • Verify or cite. Only add what you tested yourself or can link to a source.
  • Be concrete. “Cannot export DWG” beats “poor compatibility”.
  • Stay neutral. Describe features, do not advertise or bash.
  • Use your own words. Do not paste text from other databases or vendor marketing pages.
  • One app per pull request. Small changes are reviewed fastest.

For developers

Work on the tooling

git clone https://github.com/misetic99/linux-alternatives.git
cd linux-alternatives
npm install
npm run check   # validate data + tests + build the site and API
npm run dev     # preview at http://localhost:4173

Requires Node.js 20 or newer. Generate local review drafts after building with npm run tasks:verification -- --category cad --limit 5. They are written to dist/review/; builds and the preview command replace that directory. The site is plain HTML, CSS and JavaScript with no framework.
