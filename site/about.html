About the project

One missing app can stop
an entire switch to Linux.

“What replaces X on Linux?” is asked every day on forums and in support chats. Games have a great answer in ProtonDB. Everything else (CAD, engineering software, accounting, print tools, niche professional apps) had no good open source of truth. This project is that source.

What it is

Three questions, answered for every app

What replaces it?

One or more Linux alternatives per Windows app, each with a fit rating, supported file formats, shortcut similarity and a list of what is missing.

Does the original run?

Wine and Proton reports from real users: app version, runner version, distribution, the tweaks they needed, and the result.

Can my tool use it?

Yes. Everything is published as a versioned JSON API under /api/v1/, free to use with no key and no attribution.

How it works

Git is the database

Every app, alternative and report is a small YAML file. Contributors add files through pull requests, and automation checks every change before it can be merged.

  1. YAML files in Git
  2. JSON Schema validation
  3. Build
  4. Website + JSON API

Reviewable

Each change is a diff someone can read, question and revert. History shows who changed what and why.

Machine-checked

Schemas catch typos, unknown categories, missing alternatives and misplaced reports before a human ever looks at the pull request.

Derived, not typed

An app’s headline Wine status is calculated from its reports (the most common result, ties go to the newest), so the number stays honest as reports accumulate.

Static and fast

The site and the API are plain files. There is no backend to attack or to go down, and anyone can host a copy.

Reading the ratings

What the labels mean

FitMeaning
FullCovers essentially everything a typical user of the Windows app does.
GoodCovers the common workflows; gaps only in advanced features.
PartialUsable for some tasks; important features or formats are missing.
MinimalCovers only a small part of what the Windows app does.
CompatibilityMeaning
PlatinumRuns perfectly out of the box.
GoldPerfect after some tweaks.
SilverWorks, with minor issues.
BronzeRuns, with major issues.
BorkedDoes not work.
UntestedNo reports yet. This is not a promise that it works.

Principles

The rules that keep it useful

  • Verify or cite. Claims need a source or a contributor who tested them. Everything else is marked “unverified”.
  • Unknown is a valid answer. We would rather say “untested” than guess.
  • Neutral and concrete. “Cannot export DWG” beats “poor compatibility”. No advertising, no flame wars.
  • Own words. Facts are free; copying text from other databases or vendor pages is not allowed.
  • No tracking. No cookies, no analytics, no third-party scripts on this site.
  • Open forever. Data is CC0 and lives in Git, so it can always be forked.
