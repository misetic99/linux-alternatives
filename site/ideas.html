Ideas & roadmap

Where this is going,
and where you can steer it.

The roadmap shows what is built and what is next. The ideas below are open for discussion and are not promises. Pick one, challenge it, or bring your own.

Roadmap

Status of the project

Done

Foundation

Data model, JSON Schemas, validation tooling and CI that checks every pull request.

Done

Website and JSON API

Searchable site with app details and reports, plus a static, versioned API under /api/v1/.

Done

Switch planner

Personal Windows to Linux plan with fit ratings and a reviewable install script, entirely in the browser.

Done

Self-hosting kit

Docker image, hardened nginx config and an optional deploy workflow for running your own copy.

In progress

Seed the database

Growing towards the 50 to 100 most requested apps. Most entries are still unverified and need your review.

Planned

Packages

Typed npm and PyPI packages so tools can depend on the data without calling the API.

Planned

“Coming from Windows?” widget

A small embeddable section for distributions, themes and onboarding apps, built from the same JSON.

Planned

Good first issue backlog

A steady list of small, well-described tasks for new contributors.

Planned

Public launch

Announcement on community forums once the first 50 apps are in and reviewed.

Open ideas

Things we would love to explore

None of these is committed. If one excites you, open an issue and let us shape it together.

Idea

One-command compatibility report

A small CLI that detects your distribution and Wine or Proton version, asks how it went and writes a ready-to-submit report file.

Idea

Prefix presets for Bottles and Lutris

Turn well-confirmed reports into importable presets with the right winetricks verbs and settings.

Idea

Team migration assessment

Paste the list of installed programs from a Windows machine and get a readiness report for a whole team, computed locally in the browser.

Idea

Translations

Community translations of the interface and guidance, so people can find answers in their own language.

Idea

File format matrix

A browsable view of which formats each alternative reads and writes, for the question “can I still open my files?”.

Idea

Verification sprints

Themed community days where people verify one category together, for example CAD or accounting, with reviewers per domain.

Idea

Browser extension

On a Windows app’s download page, show its Linux alternatives. Offline-first and without tracking.

Idea

Freshness checks

A scheduled job that flags broken links and entries that have not been re-verified for a long time.

Idea

Software-center collections

Curated “Replacements for your Windows apps” collections that distributions can ship in their app stores.

Have a better idea?

The best features of this project will come from people who actually switched, or tried to. Tell us what would have helped you.
