Where we honestly are

Plenty of seeds, not yet proven

The database already covers many apps, and every alternative lists sourced install routes per distribution. But the entries are still community seeds: none is verified yet and there are no compatibility reports (the live numbers are on the search page). Our rule is trust before reach, so we fix that first and announce afterwards.

Roadmap

What is done and what is next

Done · v0.1

Foundation

Data model, JSON Schemas, validation tooling and CI that checks every pull request.

Done · v0.2

Website, planner and API

Search with app details and reports, the switch planner, project pages and a static, versioned JSON API under /api/v1/.

Done

Install routes per distribution

Every alternative lists installation routes with sources, so “unknown” is never confused with “unsupported”.

Done

Self-hosting and releases

Docker image and hardened nginx config. Pushes to main update GitHub Pages, version tags publish to our own server.

In progress · v0.3

Verify the seeds

Define what “verified” means, require an independent reviewer, and verify the most-searched apps first. Target: 25 verified apps.

In progress · v0.3

Fill the professional niche

CAD, engineering, accounting, printing and audio are still thin. Target: at least five apps in each before we announce.

Planned · v0.3

First compatibility reports

Real Wine, Proton and Bottles results with versions and tweaks. Target: 10 reports from at least 3 people.

Planned · v0.3

Trust tooling

Scheduled link and freshness checks, a generated good first issue backlog, report automation for non-Git users, a security policy, code owners and protected branches and tags.

Planned · v0.4

Planner 2.0

Pick your distribution and get native or Flatpak routes with sources, more export formats, a team assessment from a pasted program list, a data health page and a compare view.

Planned · v0.5

Packages and citable releases

Typed npm and PyPI packages published on tags, a JSON Schema and feed for the API, and data releases with a DOI.

Planned · v0.6

Reach

Public announcement once the data deserves it, translations, an embeddable “Coming from Windows?” widget and a browser extension.

Planned · v1.0

Stable

Stable schema, 150+ apps with at least half verified, 50+ reports, 20+ outside contributors and two downstream projects using the data.

Open ideas

Things we would love to explore

None of these is committed. If one excites you, open an issue and let us shape it together.

Idea

One-command compatibility report

A small CLI that detects your distribution and Wine or Proton version, asks how it went and writes a ready-to-submit report file.

Idea

Prefix presets for Bottles and Lutris

Turn well-confirmed reports into importable presets with the right winetricks verbs and settings.

Idea

Package availability bot

A scheduled job that checks that each listed package still exists in its distribution’s repository, and opens an issue when it does not.

Idea

Migration playbooks

Checklists beyond single apps, such as “moving a CAD workflow” or “moving a small accounting setup”, built on the data and written by people who did it.

Idea

File format matrix

A browsable view of which formats each alternative reads and writes, for the question “can I still open my files?”.

Idea

Verification sprints

Themed community days where people verify one category together, with a domain reviewer for each, for example CAD or accounting.

Idea

Printers, scanners and drivers

Notes on peripherals and vendor tools, not just applications, because a missing driver can block a switch as surely as a missing app.

Idea

Honest fallback guides

When an app truly cannot be replaced or run, document the virtual machine route and its caveats instead of pretending it does not exist.

Idea

Distribution landing pages

A page per distribution, such as “coming to Fedora from Windows”, using only routes that are sourced for that distribution.

Idea

Software-center collections

Curated “Replacements for your Windows apps” collections that distributions can ship in their app stores.

Idea

Contributor credits

Show, with consent, who verified an entry and when, so careful reviewers get visible credit and readers can judge freshness.

Idea

Accessibility audit

Regular screen-reader and keyboard testing of the site and planner, with the results published and fixed in the open.

Have a better idea?

The best features of this project will come from people who actually switched, or tried to. Tell us what would have helped you.
