Quick start

A static JSON API, no key required

Files are served from /api/v1/ with open CORS, so you can call them from a browser, a script or a build pipeline. index.json is a compact list for search, apps.json contains everything, and apps/<id>.json is one app.

curl

curl -s https://linux-alternatives.itasel.org/api/v1/index.json

JavaScript

const url = "https://linux-alternatives.itasel.org/api/v1/apps/autocad.json";
const app = await (await fetch(url)).json();
console.log(app.alternatives.map((l) => `${l.alternative.name} (${l.fit})`));

Python

import json, urllib.request

url = "https://linux-alternatives.itasel.org/api/v1/apps/autocad.json"
app = json.load(urllib.request.urlopen(url))
print([(l["alternative"]["name"], l["fit"]) for l in app["alternatives"]])

Check the verified flag before presenting an entry as fact: many entries are still unverified community seeds. The schema is versioned with the path (/api/v1/), and breaking changes will bump the version.

Why it is safe to depend on

Built to avoid lock-in

  • CC0 data. Public domain: use it commercially, embed it, redistribute it, with no attribution requirement.
  • MIT code. Tooling, site and deploy kit can be reused and modified freely.
  • Forkable by design. All data lives in Git, so you can mirror or fork the whole dataset at any time.
  • Self-hostable. The repository includes a Docker image and a hardened nginx configuration for running your own copy.
  • Private by default. This site sets no cookies, runs no analytics and loads no third-party scripts.
  • Transparent quality. Every entry says whether it is verified, and every compatibility result shows its versions and date.

Get involved

Ways organisations can help

The project is at an early stage. There are no case studies yet, and we would rather say so than invent them. Here is what is useful today.

Adopt a category

Let your domain experts verify or add the applications in their field, such as CAD, accounting, printing or engineering, through small pull requests.

Share real compatibility results

Teams that already run Windows applications on Linux can contribute reports with versions and tweaks, the most valuable data in the project.

Integrate and give feedback

Build on the API and tell us what is missing in the schema or the endpoints. Typed npm and PyPI packages are planned.

Support the project

Reviewing time, hosting and sponsorship all help. Open an issue to start a conversation about what would work for you.
